Запускаем программу в Visual Studio, после запуска открывается консольное окно.

На запрос Enter the number of elements: вводим количество элементов массива (например 6). Количество должно быть положительным и не превышать 1000.

На запрос Enter N (в нашем случае вместо N будет 6) integers: вводим указанное количество цифр через пробел.

Программа выведет сумму отрицательных элементов, расположенных между минимальным и максимальным элементами массива.

Для проверки работы программы был введён массив 4 -8 2 -5 10 3. Минимальный элемент массива — -8, максимальный — 10. Между ними находятся числа 2 и -5, поэтому результат программы равен -5.
